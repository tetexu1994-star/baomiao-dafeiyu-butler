## 🚀 快速运行与使用

### 1. 本地直接开发/调试运行
无需任何第三方重型依赖，使用 Python 标准库即可启动：
```bash
python app.py
```
启动后会自动在系统浏览器中弹出控制台界面（默认 `http://127.0.0.1:18999`）。

---

### 2. 编译为 Windows 单文件 `暴喵大肥鱼一键管家.exe`
在 Windows 环境下，只需运行：
```bash
python build_exe.py
# 或直接双击运行 build_windows.bat
```
编译完成后，会在 `dist/` 目录下生成独立的 **`暴喵大肥鱼一键管家.exe`**，体积仅 15MB 左右，可直接分享给用户使用！

## 📱 小白用户使用三步走

1. **输入主人大号 QQ**：大肥鱼只认你的大号为主人，自动防盗刷；
2. **输入机器人小号 QQ**：准备用来当大肥鱼躯体的备用 QQ 号；
3. **点击【一键部署并启动】**：
   * 自动极速下载核心组件与运行环境；
   * 自动生成并写入双端配置文件；
   * 界面直接弹出二维码，拿手机小号 QQ 扫码即可瞬间激活！
